# پلن: پاپ‌آپ صرف فعل + فیلتر نوع واژه در مخزن

شاخه: `feature/i18n-rtl` (ادامه) · تاریخ: ۲۰۲۶-۱۰-۲۶

## تصمیم‌ها

| موضوع | تصمیم |
|---|---|
| زمان‌ها | Präsens، Präteritum و Perfekt؛ هر کدام با ۶ شخص (ich، du، er/sie/es، wir، ihr، sie/Sie). |
| رنگ قرمز | فقط حروفی که نسبت به صرف باقاعده تغییر کرده‌اند: du f**ä**hrst، er f**u**hr، k**a**m، ge**gang**en. پایانه‌های عادی فعل‌های قوی (مثل `-en` در gefahren) قرمز نمی‌شوند. |
| فیلتر نوع واژه | منوی کشویی کنار فیلترهای دیگر، با نام آلمانی هر نوع + ترجمه و تعداد واژه‌ها. |

## ایمنی دیتابیس

هیچ تغییری در schema یا داده‌ی کاربران نیست. صرف فعل فقط از روی CSV (ستون‌های جدید) و قواعد ساخته می‌شود.

## یافته‌های داده

- ۷۴۸ فعل با Perfekt. سوم‌شخص مفرد Präsens برای ۷۴۶ فعل در `Formen` هست (مثل `fährt mit`، `stellt sich vor`).
- Präteritum فقط برای ۳۲۰ فعل در داده هست. بقیه یا باقاعده‌اند (از روی قاعده ساخته می‌شوند) یا فعل مرکب از یک فعل قوی‌اند (`mitfahren` ← `fahren`).
- چند مورد نامعمول: `bäckt / backt`، `Wo? liegt`، `es blitzt`، فعل‌های بازتابی، و فعل‌های چندکلمه‌ای (`Ski fahren`، `spazieren gehen`، `weh tun`).

## طراحی

### داده (ساخت در زمان build، با بررسی خودکار)
اسکریپت `scripts/build-conjugation-data.py` برای هر فعل این ستون‌ها را می‌سازد:
- **`Infinitiv`:** مصدر تمیز، بدون `sich` و حرف اضافه و توضیح. مثال: `mitfahren`، `freuen`، `Ski fahren`.
- **`Präsens`:** سوم‌شخص مفرد بدون ضمیر بازتابی. مثال: `fährt mit`، `stellt vor`.
- **`Präteritum`:** سوم‌شخص مفرد. از `Formen` خوانده می‌شود، یا برای فعل باقاعده ساخته می‌شود، یا از فعل پایه گرفته می‌شود (`fuhr` ← `fuhr mit`)، یا از فهرست دستی می‌آید.
- **`Reflexiv`:** `akk`، `dat` یا خالی (`ich freue mich` در برابر `ich merke mir`).
- **بررسی خودکار:** هر فعلی که قاعده‌ی باقاعده برایش Präsens یا Partizip متفاوتی از داده بدهد، باید Präteritum صریح داشته باشد؛ وگرنه اسکریپت متوقف می‌شود. با این کار هیچ فعل بی‌قاعده‌ای بی‌صدا «باقاعده» حساب نمی‌شود.

### موتور صرف (`src/services/conjugation.ts`، تابع خالص + تست)
- **Präsens:** ich، wir، ihr و sie از ستاک مصدر ساخته می‌شوند (`fahr-e`، `fahr-en`). du و er از فرم سوم‌شخص داده ساخته می‌شوند، تا تغییر ستاک (`fährt`) درست بیاید.
  - قواعد املایی: ستاک مختوم به t/d: `arbeitest`، `arbeitet`. مختوم به s/ß/z: `du heißt`، `du liest`. ‎-eln: `ich sammle`. ‎-ern: `wir ändern`.
  - استثناهای du: `hält → hältst`، `lädt → lädst`، `wird → wirst`.
- **Präteritum:** از سوم‌شخص مفرد.
  - قوی: `fuhr`، `fuhrst`، `fuhr`، `fuhren`، `fuhrt`، `fuhren`. ستاک مختوم به t/d/s/ß: `fandest`، `fandet`، `lasest`.
  - ضعیف و مختلط: `machte → machten`، `brachte → brachtest`.
- **Perfekt:** فعل کمکی صرف‌شده (`bin/bist/ist…` یا `habe/hast/hat…`) + Partizip از ستون `Perfekt`. اگر دو فعل کمکی مجاز باشد، هر دو نمایش داده می‌شوند.
- **جداشدنی و چندکلمه‌ای:** جزء جداشدنی یا مکمل در آخر می‌آید (`ich komme an`، `ich fahre Ski`، `es tut weh`). مثال بازتابی همراه جداشدنی: `ich rege mich auf`.
- **بازتابی:** `mich/dich/sich/uns/euch/sich` یا `mir/dir/sich/uns/euch/sich` بعد از فعل صرف‌شده (و در Perfekt بعد از فعل کمکی: `ich habe mich gefreut`).
- **فعل‌های کاملاً خاص:** جدول ثابت برای `sein`، `haben`، `werden`، `wissen`، `tun` و فعل‌های وجهی (`können`، `müssen`، `dürfen`، `sollen`، `wollen`، `mögen`)، شامل مرکب‌هایشان (`vorhaben` ← `haben`).
- **نوع فعل:** باقاعده / بی‌قاعده (قوی) / مختلط (`brachte`، `kannte`). نشانی کنار عنوان پاپ‌آپ.
- **رنگ قرمز:** هر فرم با «فرم باقاعده‌ی متناظر» مقایسه می‌شود (diff حرف‌به‌حرف به روش LCS) و حروف اضافه یا تغییرکرده قرمز می‌شوند. برای Präteritum قوی، فرم مقایسه ستاک مصدر با پایانه‌های قوی است (`fuhr` با `fahr` → فقط `u`). برای Partizip قوی، `ge + ستاک + en` است (`gefahren` → هیچ حرف قرمزی). فعل باقاعده هیچ حرف قرمزی ندارد.

### رابط کاربری
- **دکمه‌ی «صرف فعل»** روی کارت‌های فعل: پشت کارت در مرور و یادگیری کلمات جدید، و در مخزن واژگان.
- **در مرور، دکمه تا وقتی Perfekt جواب داده نشده غیرفعال است**، چون جدول Perfekt را لو می‌دهد. در مخزن همیشه فعال است.
- **پاپ‌آپ:** روی موبایل از پایین بالا می‌آید و روی دسکتاپ وسط صفحه است. عنوان: مصدر و نشان نوع فعل. سه جدول Präsens، Präteritum و Perfekt (روی دسکتاپ کنار هم، روی موبایل زیر هم). راهنما: «حروف قرمز = تغییر بی‌قاعده».
  - با Esc یا کلیک بیرون بسته می‌شود. فوکوس داخل پاپ‌آپ می‌ماند و بعد از بستن به دکمه برمی‌گردد.
  - جدول‌ها همیشه چپ‌به‌راست‌اند (آلمانی)، حتی در رابط فارسی.
  - میانبرهای مرور (Space و 1 و 2) وقتی پاپ‌آپ باز است کار نمی‌کنند.
- **فیلتر نوع واژه در مخزن:** منوی کشویی «همه‌ی انواع / Verb (فعل) · ۷۴۹ / Nomen (اسم) · ۲۰۲۰ / …». با بقیه‌ی فیلترها و جست‌وجو ترکیب می‌شود، و انتخاب‌ها و «انتخاب همه» فقط روی نتیجه‌ی فیلترشده کار می‌کنند.

## کرنر کیس‌ها (چک‌لیست تست)

**صرف:**
- [x] باقاعده (`machen`، `lernen`): هیچ حرف قرمزی نیست
- [x] ستاک t/d (`arbeiten`، `finden` → `du findest`، `ihr fandet`)
- [x] ستاک s/ß/z (`heißen` → `du heißt`؛ `lesen` → `du liest`، `du lasest`)
- [x] ‎-eln و ‎-ern (`sammeln` → `ich sammle`؛ `ändern` → `wir ändern`)
- [x] تغییر ستاک (`fahren` → `du fährst`؛ `nehmen` → `du nimmst`؛ `halten` → `du hältst`؛ `laden` → `du lädst`)
- [x] قوی / مختلط (`kommen` → `kam`؛ `bringen` → `brachte`؛ `kennen` → `kannte`؛ `denken` → `dachte`)
- [x] جداشدنی (`ankommen` → `ich komme an`، `er kam an`، `ich bin angekommen`)
- [x] پیشوند جدانشدنی و ‎-ieren (`verstehen` → `verstanden`؛ `studieren` → `studiert`)
- [x] بازتابی Akk و Dat، و بازتابی همراه جداشدنی (`sich vorstellen` → `ich stelle mich vor`)
- [x] چندکلمه‌ای (`Ski fahren`، `spazieren gehen`، `weh tun`)
- [x] دو فعل کمکی (`schwimmen`، `fahren`، `rudern`)
- [x] جدول ثابت (`sein`، `haben`، `werden`، `wissen`، `tun`، فعل‌های وجهی) و مرکب‌هایشان (`vorhaben`)
- [x] فعل‌های غیرشخصی (`es blitzt`): همه‌ی اشخاص نمایش داده می‌شوند، چون صرفشان ممکن است. بازبینی می‌شود.
- [x] فعل بدون Perfekt (`geboren sein`) یا کارت دستی بدون داده: دکمه نمایش داده نمی‌شود

**رابط کاربری:**
- [x] دکمه پیش از جواب Perfekt غیرفعال است و بعد از جواب فعال می‌شود
- [x] پاپ‌آپ در موبایل و دسکتاپ، فارسی و انگلیسی، با جدول چپ‌به‌راست
- [x] Esc، کلیک بیرون، برگشتن فوکوس، و غیرفعال بودن میانبرها وقتی پاپ‌آپ باز است
- [x] فیلتر نوع + درس + جست‌وجو با هم؛ شمارش‌ها درست باشند
